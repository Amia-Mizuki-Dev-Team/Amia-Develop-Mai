## 一、DX Rating 计算

### 单曲 Rating

```
单曲Rating = floor( 定数 × (达成率/100) × 评级系数 )
```

- 达成率单位为 %，按 **100.5% 封顶**
- 结果**向下取整**（与游戏一致）

### B50

```
B50 = 全部成绩记录按单曲Rating降序排列，取前 50 首的单曲Rating之和
```

### 上分推演（贪心替换）

教学工具常按以下两阶段推演"打到目标 Rating 需要补哪些歌"：

1. **阶段一（已入榜提升）**：B50 内未到 SSS+ 的曲目，收益 = SSS+ 可达分 − 当前分
2. **阶段二（未入榜挤入）**：B50 外曲目，收益 = SSS+ 可达分 − 当前 B50 最低分

限制条件：推荐曲目的定数不超过玩家 B50 平均定数 + 0.7（约一级）；收益相同时难度档低者优先。

## 二、难度档位规则

排序 tie-break 使用的难度档位划分：

- 小数点后 0~5 为一档（如 13.0~13.5）
- 小数点后 6~9 为高一档（如 13.6~13.9）
- 分水岭示例：13.5 / 13.6、13.9 / 14.0
