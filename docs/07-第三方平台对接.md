# 10 · 第三方平台对接

本文描述逆向工具链下游的社区查分平台对接：落雪（LXNS）、水鱼（diving-fish）以及曲目分类数据源。

## 一、平台总览

| 平台 | 定位 | 对接方式 |
|---|---|---|
| 落雪 LXNS | 成绩上传/查询社区平台 | OAuth 2.0 授权 + REST API |
| 水鱼 diving-fish | 老牌查分平台 | 公开 API（含 Dev API） |
| dxrating.net | 曲目分类社区站 | 公开网页/接口（分类数据） |

## 二、落雪（LXNS）OAuth 授权

### 授权模式

使用 **OAuth 2.0 设备码模式**（device flow）：回调地址为 `urn:ietf:wg:oauth:2.0:oob`（即无浏览器回调，用户手动回填授权码）。

### Token 生命周期

| Token | 有效期 |
|---|---|
| Access Token | 15 分钟 |
| Refresh Token | 30 天 |

### 错误响应格式

所有错误响应统一为 JSON：

```
{ "success": false, "code": <错误码>, "message": "<描述>" }
```

| 错误码 | 含义 |
|---|---|
| 400 | 参数错误 |
| 401 | 鉴权失败 |
| 403 | 权限不足 |
| 404 | 不存在 |
| 429 | 限流 |
| 500 | 服务器错误 |

### 成绩上传

- 端点：`POST /api/v0/user/maimai/player/scores`
- 请求体：`{ "scores": [ ... ] }`

### 曲目 ID 规则

- **宴会场曲目**：ID 大于 100000
- **DX 曲目**：上传前需做 ID 归一化（`DX曲目ID % 10000` 还原为原曲 ID）

## 三、水鱼（diving-fish）

- 提供玩家 B50（Best 50）与全量成绩查询 API
- 常作为落雪数据不可用时的**降级数据源**
- 已知其部分响应中谱面定数字段可能缺失（如硬编码为 0），消费方需从本地曲库回填

## 四、曲目分类数据源（dxrating.net）

社区维护的曲目分类体系，为教学分析提供标签数据：

| 分类维度 | 说明 | 典型标签 |
|---|---|---|
| cat（谱面类型） | 谱面宏观特征 | 星星谱、键盘谱、体力谱、底力谱、高物量 |
| con（技能特征） | 具体键型技巧 | 转圈、错位、纵连、扫键、散打、交互、爆发、拆弹、定拍、大位移、反手、一笔画、跳拍等 |
| tag（社区评价） | 难度口碑 | 诈称谱、水 |

获取方式为抓取公开页面/接口数据（绕过常规反自动化检测属于该数据源侧的实践，本文仅记录数据存在性）。

## 五、数据源层级设计

协议实现与教学工具通常按以下层级组织数据源：

```
玩家成绩数据: 落雪 B50 源（首选） → 水鱼全量 API（降级）
曲目元数据:   更新分发通道解出的 XML（权威） → 社区曲库（兜底）
定数/谱面:    XML 谱面数据（权威） → 本地缓存曲库
分类标签:     dxrating 分类数据（教学用途）
```

- 权威数据（定数、谱面）始终以更新分发通道产物为准，社区数据仅作兜底与展示增强
- 平台凭据（client_id/secret 等）均不公开，见 agent.md 脱敏红线
