# Amia-Develop-Mai

舞萌（maimai DX）**协议分析与开发文档**公开仓库，隶属 **Amia-Mizuki-Dev-Team**。

本仓库从协议逆向分析的视角，整理舞萌国服街机相关的技术资料，覆盖机台与服务器之间的通信协议、鉴权与加密机制、数据模型与核心算法、更新分发通道以及第三方查分平台对接。文档以"讲清原理"为目标：协议事实以伪代码、公式与表格呈现，**不公开任何可复现的凭据**。
